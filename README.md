# Nsolver
Solver for semiring semantics of first-order logic for the natural semiring.

For semirings semantics read:Isomorphism Versus Elementary Equivalence and EF-games in Semiring Semantics http://hdl.handle.net/10138/629936

The solver takes as input a N-interpretation $\pi$ and a first-order formula $\psi$ and outputs $\pi(\psi)$
